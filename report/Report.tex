\caption{Spark Decision Tree}
\begin{algorithmic}[1]

\State Parse the input/output directories and number of runs
\State Initialise the Spark session and load the data from the provided input directory

\Statex Generate schema
\Statex \textbf{Setup the pipeline as follows:}

\State Index required columns
\State One-hot encode required columns
\State Assemble into feature columns
\State Append parameterised DecitionTree model as the final stage.
\Statex \textbf{Run the pipeline:}
\State Split the test/training data into num\_runs instances
\State Foreach training data, train a model
\Statex \textbf{Evaluate the results:}
\State Output the DecisionTree structure for the first tree
\State Foreach (model, training data) pair, generate predictions
\State Foreach (model, testing data) pair, generate predictions
\State Foreach training prediction, generate an accuracy row
\State Foreach test prediction, generate an accuracy row
\State Produce a CSV with the aggregate data by test/train
\State Produce a CSV with the per-run data
\State Display results

\end{algorithmic}
\end{algorithm}

How to Install and Run Group22's Decision Tree and Logistic Regression code on the Hadoop cluster

Important note on Makefile:

\textbf{Part 1: Setup \& Environment}

\begin{enumerate}
    \item Ensure that you have a user directory on the HDFS cluster (if you do not have one, create one)
    \item Download the submitted Tarball into a folder on your ECS desktop
    \item Extract the tarball (alternatively you can clone our git repo)
    \item cd into the extracted folder
\end{enumerate}

\textbf{Part 2: Understanding the Directory Layout}

Directories:

\begin{itemize}
    \item \texttt{SparkWordCount/input} - the dataset extracted and ready for use
    \item \texttt{SparkWordCount/bin} - where the code is placed
    \item \texttt{SparkWordCount/staged\_output} - where local runs place their output instead of HDFS

    \item \texttt{DecisionTree/input} - the dataset extracted and ready for use
    \item \texttt{DecisionTree/bin} - where the code is placed
    \item \texttt{DecisionTree/staged\_output} - where local runs place their output instead of HDFS

    \item \texttt{LogisticRegression/input} - the dataset extracted and ready for use
    \item \texttt{LogisticRegression/bin} - where the code is placed
    \item \texttt{LogisticRegression/staged\_output} - where local runs place their output instead of HDFS

    \item \texttt{ecs\_hadoop\_env} - the ECS cluster Hadoop makefile variables
    \item \texttt{ecs\_spart\_env} - the ECS cluster Spark makefile variables
    \item \texttt{local\_hadoop\_env} - the Hadoop makefile variables for local execution
    \item \texttt{local\_spark\_env} - the Hadoop makefile variables for local execution
\end{itemize}

\textbf{Part 3: How to run the code}

The makefile supports two execution modes, ecs and local, picked via a ENV environment variable. "ecs" is the default.

The makefile will ensure proper configured access to kerberos, HDFS and Spark before attempting to launch the job.

This is configured to run via makefile. To run a variant:

\textbf{Part 3a: Decision Tree}

\begin{verbatim}
$ make submit_DecisionTree
\end{verbatim}

The output will be placed in:

\begin{verbatim}
DecisionTree/output
\end{verbatim}

\begin{verbatim}
$ cat DecisionTree/output/*.csv
\end{verbatim}

To clean the files when complete:

\begin{verbatim}
$ make clean_DecisionTree
\end{verbatim}

\textbf{Part 3b: Logistic Regression}

\begin{verbatim}
$ make submit_LogisticRegression
\end{verbatim}

The output will be placed in:

\begin{verbatim}
LogisticRegression/output
\end{verbatim}

\begin{verbatim}
cat LogisticRegression/output/*.csv
\end{verbatim}

To clean the files when complete:

\begin{verbatim}
$ make clean_LogisticRegression
\end{verbatim}

\textbf{Optional Variant modes:}

Runs spark wordcount

\begin{verbatim}
$ make submit_SparkWordCount
\end{verbatim}

To Run all modes

\begin{verbatim}
$ make all
\end{verbatim}

The output(s) will be placed in:

\begin{verbatim}
DecisionTree/output
LogisticRegression/output
SparkWordCount/output
\end{verbatim}

\begin{verbatim}
$ cat DecisionTree/output/*.csv
$ cat LogisticRegression/output/*.csv
$ cat SparkWordCount/output/*.csv
\end{verbatim}

To clean the files when complete:

\begin{verbatim}
$ make clean_DecisionTree
$ make clean_LogisticRegression
$ make clean_SparkWordCount
\end{verbatim}

or

\begin{verbatim}
$ make clean
\end{verbatim}
