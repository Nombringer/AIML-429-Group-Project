    \item Extract the tarball
    \item cd into the extracted folder
\end{itemize}

\textbf{* How to install}

If you are reading this, it is installed.

\textbf{* Directory Layout}

\begin{itemize}
    \item \texttt{SparkWordCount/input} - the dataset extracted and ready for use
    \item \texttt{SparkWordCount/bin} - where the code is placed
    \item \texttt{SparkWordCount/staged\_output} - where local runs place their output instead of HDFS

    \item \texttt{DecisionTree/input} - the dataset extracted and ready for use
    \item \texttt{DecisionTree/bin} - where the code is placed
    \item \texttt{DecisionTree/staged\_output} - where local runs place their output instead of HDFS

    \item \texttt{LogisticRegression/input} - the dataset extracted and ready for use
    \item \texttt{LogisticRegression/bin} - where the code is placed
    \item \texttt{LogisticRegression/staged\_output} - where local runs place their output instead of HDFS

    \item \texttt{ecs\_hadoop\_env} - the ECS cluster Hadoop makefile variables
    \item \texttt{ecs\_spart\_env} - the ECS cluster Spark makefile variables
    \item \texttt{local\_hadoop\_env} - the Hadoop makefile variables for local execution
    \item \texttt{local\_spark\_env} - the Hadoop makefile variables for local execution
\end{itemize}

\textbf{* How to run}

The makefile supports two execution modes, ecs and local, picked via a ENV environment variable. "ecs" is the default.

The makefile will ensure proper configured access to kerberos, HDFS and Spark before attempting to launch the job.

This is configured to run via makefile. To run a variant:

\begin{verbatim}
$ make submit_DecisionTree
$ make submit_SparkWordCount
$ make submit_LogisticRegression
\end{verbatim}

or optionally

\begin{verbatim}
$ make all
\end{verbatim}

The output will be placed in:

\begin{verbatim}
DecisionTree/output
LogisticRegression/output
SparkWordCount/output
\end{verbatim}

\begin{verbatim}
$ cat DecisionTree/output/*.csv
$ cat LogisticRegression/output/*.csv
$ cat SparkWordCount/output/*.csv
\end{verbatim}

To clean the files when complete:

\begin{verbatim}
$ make clean_DecisionTree
$ make clean_LogisticRegression
$ make clean_SparkWordCount
\end{verbatim}

or

\begin{verbatim}
$ make clean
\end{verbatim}
